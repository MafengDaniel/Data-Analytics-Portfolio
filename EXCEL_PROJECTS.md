# Excel Projects

## Corporate Financial Scenario & Runway Model

**Domain:** Financial Planning & Analysis

**Primary Tools:** Excel, Dynamic Arrays, VBA

**Business Metric:** 
- 24-month liquidity forecast
- 18 scenario paths
- $2.3M burn-rate sensitivity

### Project Overview
Advanced financial modeling solution integrating 3-statement analysis with multi-scenario simulation capabilities. Built with dynamic arrays and VBA automation for real-time scenario analysis and sensitivity testing.

### Key Features
- **3-Statement Integration:** Income statement, balance sheet, and cash flow forecasting
- **Scenario Analysis:** 18 distinct scenario paths for business planning
- **Sensitivity Analysis:** Variable impact modeling on key financial metrics
- **Cash Flow Forecasting:** 24-month forward-looking liquidity projections
- **Burn Rate Modeling:** Dynamic burn-rate calculations with sensitivity ranges
- **Interactive Controls:** VBA-driven dashboards for scenario selection and result visualization

### Skills Demonstrated
- Advanced Excel formulas and Dynamic Arrays
- VBA macro development for automation
- Financial statement modeling
- Scenario and sensitivity analysis
- Data visualization in Excel
- Business logic implementation

### File Location
`02_financial_scenario_model/` directory

## How to Use These Models

1. **Open the Excel workbook** from the project directory
2. **Navigate to the Dashboard sheet** for high-level overview
3. **Adjust scenario inputs** on the Inputs sheet
4. **Review assumptions** in the Assumptions sheet
5. **Analyze results** across the Financial Statements and Sensitivity Analysis sheets
