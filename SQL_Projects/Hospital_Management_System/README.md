# Hospital Management System SQL Project

A MySQL portfolio project demonstrating relational database design and analysis for a hospital management system.

## Included tables

- `departments` — hospital departments and annual budgets
- `doctors` — doctors, specialties, departments, salaries, and active status
- `patients` — patient demographics and registration details
- `appointments` — patient appointments, doctors, statuses, and notes
- `bills` — appointment billing, payment status, and payment methods

## Analysis demonstrated

The SQL script includes examples of:

- Database and table creation with primary and foreign keys
- Data insertion
- Filtering with `WHERE`, `AND`, `OR`, `IN`, `BETWEEN`, `LIKE`, and null checks
- Sorting and limiting results
- Aggregations with `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`
- `GROUP BY`, `HAVING`, and `CASE` expressions
- Inner, left, and right joins
- Nested queries and reporting queries

Run `hospital_management_system.sql` in MySQL Workbench or another MySQL-compatible client.
